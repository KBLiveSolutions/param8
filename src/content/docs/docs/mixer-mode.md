title: Global Mode
description: Global mixer controls (Preset 7)
---

Preset 7 (**Global**) provides direct access to Ableton Live's mixer and transport controls via the Remote Script.

The header shows the selected track name on the left and "Global" on the right.

## Encoders

| 1 | 2 | 3 | 4 |
|:---:|:---:|:---:|:---:|
Master Volume | Cue Volume | Tempo | Scene Select | Selected Track |
| **5** | **6** | **7** | **8** |
| Selected Track Volume | Selected Track Pan | Position | Last Selected Parameter |

## Buttons

| 1 | 2 | 3 | 4 |
|:---:|:---:|:---:|:---:|

| **5** | **6** | **7** | **8** |
| Mute | Solo | Arr. Loop | Return to default value |
