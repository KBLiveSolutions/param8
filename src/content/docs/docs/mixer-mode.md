---
title: Mixer Mode
description: Global mixer controls (Preset 7)
---

Preset 7 (**Global**) provides direct access to Ableton Live's mixer and transport controls via the remote script.

The header shows the selected track name on the left and "Global" on the right.

## Controls

| | 1 | 2 | 3 | 4 |
|:---|:---:|:---:|:---:|:---:|
**Turn** | Master Volume | Cue Volume | Tempo | Scene Select | Selected Track |
**Push** | Metronome | Arm | Play / Stop | Launch Scene | 

| | **5** | **6** | **7** | **8** |
|:---|:---:|:---:|:---:|:---:|
**Turn**  | Selected Track Volume | Selected Track Pan | Position | Last Selected Parameter |
**Push** | Mute | Solo | Arr. Loop | Return to default value |
