## Specs

| | |
|---|---|
| **Encoders** | 8× infinite rotary with push-button |
| **Buttons** | 8× momentary or toggle |
| **Displays** | 2× OLED 256×64 px |
| **MCU** | Raspberry Pi Pico (RP2040) |
| **Connection** | USB-C (class-compliant MIDI) |
| **Compatibility** | Ableton Live (dedicated remote script), any DAW via MIDI |
