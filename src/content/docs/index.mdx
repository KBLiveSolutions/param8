## Features

<CardGrid>
  <Card title="8 Push-Encoders" icon="setting">
    Infinite rotation with push-button. Relative or absolute MIDI CC, fully configurable per preset.
  </Card>
  <Card title="Dual OLED Displays" icon="laptop">
    Two 256×64 SSD1322 displays showing parameter names, values, and visual feedback in real time.
  </Card>
  <Card title="6 User Presets + 2 Built-in" icon="list-format">
    6 fully customizable presets for your mappings, plus dedicated Mixer and Device modes for Ableton Live.
  </Card>
  <Card title="Latch & Revert" icon="random">
    Queue encoder changes and release them at once, or revert to undo your last tweaks.
  </Card>
  <Card title="3 Display Layouts" icon="document">
    Dynamic, Compact, or Stacked — switch display layouts via SysEx or the web editor.
  </Card>
  <Card title="Web Editor" icon="external">
    Configure presets, MIDI mappings, button modes, and display settings from your browser via WebMIDI.
  </Card>
</CardGrid>

## Specs

| | |
|---|---|
| **Encoders** | 8× infinite rotary with push-button |
| **Buttons** | 8× momentary or toggle |
| **Displays** | 2× SSD1322 OLED 256×64 px |
| **MCU** | Raspberry Pi Pico (RP2040) |
| **Connection** | USB-C (class-compliant MIDI) |
| **Compatibility** | Ableton Live (dedicated remote script), any DAW via MIDI |
| **Firmware** | Open source, updatable via UF2 |
