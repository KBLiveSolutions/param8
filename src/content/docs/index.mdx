## Features

<div class="features-frame">
  <CardGrid>
    <Card title="Visual Feedback & Precise Control" icon="setting">
    See parameter names, values, and button states instantly on the dual 256×64 OLED high-contrast displays. <br/>
    The 8 push-encoders always stay in sync with your DAW, so your controls are always correctly positioned with no pickup issues. Press to toggle buttons, turn to adjust values.
    </Card>
    <Card title="6 User / 2 Ableton Built-in Presets" icon="list-format">
    Two dedicated presets for Ableton Live :<br/>
    ➞ **Global** mode for Levels, Pans, Transport and more <br/>
    ➞ **Device** mode for hands-on Instrument or Effect control with device navigation.<br/> 
    Plus 6 fully configurable user presets for any MIDI software or hardware.
    </Card>
    <Card title="Customize your MIDI Mappings" icon="pencil">

    The controller's auto-naming feature learns parameter names from Ableton Live, so your displays always show meaningful labels instead of generic CC numbers.
    </Card>
    <Card title="Enhance your performance with Latch & Revert" icon="random">
    **Latch** ➞ tweak parameters behind the scenes, then **apply all changes at once**. Perfect for dramatic live transitions.<br/>
    **Revert** ➞ create a snapshot, experiment freely with any parameters, then **roll back to the original state in one press**.
    </Card>
    <Card title="Online Editor" icon="external">
