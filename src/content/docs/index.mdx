## Features

<div class="features-frame">
  <CardGrid>
    <Card title="8 Push-Encoders" icon="approve-check-circle">
    Infinite rotary encoders with push-button — no pickup issues, always in sync with your DAW. Unlike standard potentiometers, endless encoders never jump when switching presets or banks. Press to toggle buttons, turn to adjust values.
    </Card>
    <Card title="Dual OLED Displays" icon="laptop">
    Two 256×64 OLED screens provide instant visual feedback: parameter names, current values, and button states update in real time. Each display covers 4 encoders, so you always know what you're tweaking without looking at your screen.
    </Card>
    <Card title="Latch & Revert" icon="random">
    **Latch**: silently tweak multiple parameters behind the scenes, then apply all changes at once — perfect for dramatic live transitions.<br/>**Revert**: experiment freely with any parameters, then roll back to the original state in one press if it doesn't sound right.
    </Card>
    <Card title="Custom MIDI Mappings" icon="pencil">
    Name your encoders and buttons, assign any CC or Note on any MIDI channel, per preset. The controller's auto-naming feature learns parameter names from Ableton Live, so your displays always show meaningful labels instead of generic CC numbers.
    </Card>
    <Card title="6 User + 2 Built-in Presets" icon="list-format">
    Two dedicated presets for Ableton Live — Mixer mode for levels, pans, and sends, and Device mode for hands-on instrument control with automatic bank switching. Plus 6 fully configurable user presets for any MIDI software or hardware.
    </Card>
    <Card title="Online Editor" icon="external">
    Configure everything from your browser: rename controls, assign CCs, organize presets, and upload your configuration — all via WebMIDI with no software to install. Works on any platform with a compatible browser.
    </Card>
  </CardGrid>
</div>

## Specs

| | |
|---|---|
| **Encoders** | 8× infinite rotary with push-button |
| **Buttons** | 8× momentary or toggle |
| **Displays** | 2× OLED 256×64 px |
| **MCU** | Raspberry Pi Pico (RP2040) |
| **Connection** | USB-C (class-compliant MIDI) |
| **Compatibility** | Ableton Live (dedicated remote script), any DAW via MIDI |
| **Accessories** | USB-C Cable and 45° stands |
